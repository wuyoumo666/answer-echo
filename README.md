## 本版优化

2026-10-17：答案页左上角新增「首页」，返回输入页时保留问题与分类，方便修改。底部「再问一次」沿用当前问题与分类，直接进入原有揭晓动画并抽取新答案，不先返回首页；取消或切后台时回到上一条答案。已有回响保留，保存失败时会先重试，避免覆盖未保存的答案。

2026-10-17：订阅未来提醒成功且状态保存完成后，中央播放一次「信纸收入信封 → 合拢 → 折成纸飞机 → 飞走」动画，约 3 秒，可轻触跳过。使用 WXSS 的 transform / opacity，不新增图片、视频、动效库或逐帧 JS；结束卸载元素，切后台或销毁页面清理兜底计时，适配减少动态偏好。拒绝授权、云端失败或本地状态保存失败时不会播放成功动画。真机帧率与内存峰值尚未测量。

补齐折叠屏和平板：启用自动旋转和可调整窗口，按当前窗口宽度适配，600px 起使用稳定的像素尺寸、首页左右分栏与双列历史；960px 起答案与辅助操作分栏。宽屏回信、未来留言、直觉和分享弹层居中且限制宽度，低高度横屏保留滚动。旋转、折叠尺寸变化和分屏不会主动清空提问、回信、未来留言或已有答案。

已在微信模拟器检查 768×1024、1024×768、440×707、707×440 四种尺寸。真实硬件折叠过程、各厂商分屏和悬浮键盘仍需具体设备确认。宽屏样式由 `node tools/build-adaptive.cjs` 生成；调整 `pages/index/index.wxss` 或 `tools/wide-layout.wxss` 后需重新生成，`tools` 不进入小程序包。

新增「先听见自己」：揭晓前选择继续、停下或还不知道，也可以直接跳过。直觉与读到答案后的感受留在本机，不改变随机抽取规则。

新增「回响有了后来」：在历史详情中记录我行动了、我换了方向、已经不困扰了，与原有回信一起保存。支持随时修改，未保存离开会提醒。

新增「写给未来的回响」：从当前答案或历史详情封存一张卡片和最多 300 字留言，选择未来日期，在我的回响中到期打开。普通历史保留 200 条，未来信封独立保留最多 50 封，满额时不自动覆盖旧信。可单独选择微信到期提醒；不订阅也能封存、到期打开。换设备或清理本机数据后，信件正文不会自动恢复。

手机细节调整：轻操作至少 44px 触摸范围；回信和未来留言输入时避让键盘并滚入输入区；键盘打开和页面切后台时暂停背景动画；长答案、长解释、长留言可换行和滚动。模拟器与键盘高度事件检查不能替代手机真实键盘、帧率和相册授权确认。

输入栏采用细四色渐变描边与浅白内层，搭配书写图标、引号提示和分隔线。主按钮保持蓝色，箭头采用柔和圆形底座；聚焦时边缘和阴影轻微加强。保持一个主操作，沿用原多行输入和本地保存逻辑。

重新调整首页留白、输入卡片与文字层级。多行输入支持自动增高；答案根据长度调整字号和语句换行。首页、答案与历史之间具有退出和进入过渡，历史筛选带滑动指示，收藏和保存使用统一轻提示，回信弹层具有完整进出动画。

2026-10-15 增加 Logo 转场：点击「听听回响」后，页面让出留白，沿用原 Logo 图案完成一次 900 ms 的平滑旋转，收稳后以 200 ms 淡出接到答案卡片。只在这次操作中播放一次，不新增图片或动效依赖。转场期间可以取消，切到后台会停止；答案保存后不再响应取消，避免界面与记录不一致。

## 功能与数据

- 80 条原创灵感句，四类各 20 条；保留 40 条主句、替换 40 条相近内容，重新整理配套解释。
- 抽取避开最近 8 次相同答案，并优先避开最近 3 条可识别答案的相近主题。
- 自动保存最近 200 次记录，支持收藏、搜索和回信。
- 左上角进入历史，首页保留一个主操作。
- 原有存储键 `answer-echo-v2` 不变，历史数据无需迁移。
- 退役答案编号不复用，旧记录保持当时的原文、解释、收藏和回信。
- 问题、直觉、答案、回信和未来留言默认保存在当前设备，清理数据或换设备后不会自动恢复。主动生成并分享卡片时，图片会包含所选记录的问题与答案。
- 仅在用户订阅到期提醒时，云端保存信封编号、日期与发送所需的收件标识，不上传信件正文；删除已申请提醒的信封前会联网取消任务。清理数据前应先取消已订阅信封。
- 分享入口生成本地 PNG 答案卡片，包含问题、答案、解释、分类和品牌。问题用浅色小字，答案沿用大字号；不包含回信、未来留言或小程序码。生成后可先预览再决定是否分享；未填写问题时省略问题区。
- 支持的微信版本使用图片分享菜单，并明确关闭附带小程序入口；不支持时提供保存到相册与查看大图。
- 微信右上角普通转发已恢复，发送给朋友或分享到朋友圈使用固定品牌封面，只打开首页，不带问题、回信、直觉或封存内容。答案页的分享按钮仍生成纯图片卡片。
- 相册权限仅在用户点击保存时申请，取消不会显示为保存或发送成功。

## 包体积

界面 Logo 为 256×256 压缩 PNG，分享图为 500×400 PNG。独立头像、旧版素材和模板组件通过 `packOptions.ignore` 排除。JS、WXML、WXSS 压缩保持启用，高清母版不纳入主包。
